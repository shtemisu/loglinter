# Правила loglinter

## Что считается сообщением

Сообщение — это строковый литерал, переданный в вызов логгера как текст лога:

- `log.Print*`, `log.Fatal*`, `log.Panic*` — первый аргумент;
- `slog.Debug/Info/Warn/Error` и методы `*slog.Logger` — первый аргумент;
- `slog.*Context` — второй аргумент (первый — `ctx`);
- методы `*zap.Logger` и `*zap.SugaredLogger` — первый аргумент.

Перед проверкой сообщение приводится к виду, который увидит пользователь:

1. Литерал распаковывается: `"line\n"` → `line` + перевод строки.
2. В методах с суффиксом `f` (`Printf`, `Infof`, …) глаголы форматирования (`%d`, `%s`, `%v`, `%-5.2f`, …) удаляются, `%%` превращается в `%`.

Если сообщение не строковый литерал (переменная, вызов функции), правила 1, 3, 4 к нему не применяются.

---

## 1. Английский язык

**Нарушение:** сообщение содержит хотя бы одну букву, не относящуюся к латинице.

Цифры, пробелы, знаки препинания и эмодзи этим правилом **не проверяются** — это задача правила 3.

| Сообщение | Результат |
|---|---|
| `"server started"` | ✅ |
| `"port 8080"` | ✅ |
| `"server started!🚀"` | ✅ (нарушает правило 3) |
| `"ошибка подключения"` | ❌ |
| `"server запущен"` | ❌ |

---

## 2. Чувствительные данные

**Нарушение:** ключевое слово из списка встречается **как отдельное слово** в одном из мест:

- текст сообщения;
- имя переменной, переданной в вызов как аргумент или участвующей в конкатенации (`"token: " + token`);
- ключ атрибута `slog` (`"password", pwd`) или имя поля `zap` (`zap.String("token", t)`).

**Слово** — непрерывная последовательность букв и цифр. Разделители — всё остальное, включая `_` и `-`. Сравнение без учёта регистра.

**Ключевые слова:** `password`, `passwd`, `pwd`, `pass`, `token`, `jwt`, `apikey`, `api_key`, `secret`, `private`, `credential`, `credentials`, `auth`, `authorization`, `bearer`, `cookie`.

Составные ключи (`api_key`, `api-key`) после разбиения на слова превращаются в пару `api` + `key` и ищутся как последовательность слов.

| Вызов | Результат |
|---|---|
| `log.Print("operation passed")` | ✅ `passed` ≠ `pass` |
| `log.Print("author not found")` | ✅ `author` ≠ `auth` |
| `log.Print("auth failed")` | ❌ |
| `log.Println("login:", password)` | ❌ имя переменной |
| `log.Print("token: " + tok)` | ❌ слово в тексте |
| `log.Print("user_password")` | ❌ `user` + `password` |
| `slog.Info("login", "password", pwd)` | ❌ ключ атрибута |

---

## 3. Спецсимволы и эмодзи

**Нарушение:** сообщение содержит символ, не входящий в разрешённый набор.

**Разрешено:** буквы, цифры, пробел, `:`, `'` (апостроф: `can't`), `.`, `,`, `[`, `]`.

Две и более точки подряд (`..`, `...`) — нарушение.

Всё остальное запрещено, в том числе `;` `/` `\` `{` `}` `(` `)` `-` `_` `!` `?` , кавычки и эмодзи, символ перехода строки.

Глаголы форматирования к этому моменту уже удалены (см. «Что считается сообщением»), поэтому `%d` нарушением не считается.

| Сообщение | Результат |
|---|---|
| `"failed to connect: timeout"` | ✅ |
| `log.Printf("got %d items", n)` | ✅ |
| `"connection failed!!!"` | ❌ `!` |
| `"server started🚀"` | ❌ эмодзи |
| `"user_id not found"` | ❌ `_` |
| `"failed to read config.yaml"` | ✅ |
| `"retry 3, giving up"` | ✅ |
| `"something went wrong..."` | ❌ `...` |
| `"value {id}"` | ❌ `{` `}` |

---

## 4. Регистр первой буквы

**Нарушение:** первый символ сообщения — заглавная буква.

**Исключения** — первое слово сообщения (последовательность букв и цифр до первого другого символа):

- целиком состоит из заглавных латинских букв и цифр и длиннее одного символа — это аббревиатура (`HTTP`, `GRPC`, `S3`, `JSON`);
- входит в список имён собственных `properNames` в `rules.go` (`Redis`, `PostgreSQL`). Аббревиатуры в этот список добавлять не нужно.

Пустое сообщение этим правилом не проверяется.

| Сообщение | Результат |
|---|---|
| `"server started"` | ✅ |
| `"8080 port busy"` | ✅ первый символ не буква |
| `"HTTP request failed"` | ✅ аббревиатура |
| `"S3 upload failed"` | ✅ аббревиатура |
| `"Redis connection lost"` | ✅ имя из списка |
| `""` | ✅ не проверяется |
| `"Server started"` | ❌ |
| `"A request failed"` | ❌ одна буква — не аббревиатура |
| `"HTTPServer started"` | ❌ слово не целиком заглавное |
